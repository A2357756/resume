    • 事件關聯邏輯開發將紅隊攻擊紀錄與藍隊修補事件自動配對的核心判斷邏輯
    • 偵測規則設計定義各攻擊手法的識別條件與分類規則（對應 MITRE ATT&CK 框架）

  • 虛擬健身教練 — Xsens 動作偵測與評分系統

    作品介紹

    角色：後端工程師 / Rep 判斷狀態機・評分邏輯・認證與資安防護

    結合 Xsens 慣性感測器的健身動作偵測系統，即時分析使用者的運動姿勢，並計算完成次數與動作評分。系統分為健身房現場（即時視覺回饋）與家用網頁（歷史紀錄查詢）兩種使用情境，後端服務負責訓練資料的驗證、評分與儲存。

    後端採用「不信任客戶端」的設計：感測端只負責回報原始角度資料，動作是否有效、完成幾下、分數多少，一律由後端重新驗證與計算，避免分數被偽造。

    負責後端 FastAPI 服務開發：

    • Rep 判斷狀態機以「站立→下降→最低點→上升→完成」五階段判斷一次完整動作，並設計防呆機制，單純晃動或沒蹲到底的動作不會被誤算為一次
    • 評分邏輯設計與 PM 討論評分規則，區分即時視覺回饋、里程碑與整組評分三個層次，各自採用適合的判斷方式
    • 認證與權限實作 JWT 雙軌身分驗證（使用者／裝置）、Email 驗證碼註冊與密碼重設流程，並以 IDOR 防護確保使用者只能存取自己的資料
    • 資安防護登入 Rate Limiting、請求大小限制，以及串接外部服務（寄信、圖片簽署）時的容錯處理，確保外部服務異常不會拖垮核心 API
    • 部署驗證於 Linux VM 環境部署、排查環境差異問題並完成端到端測試

    技術： Python・FastAPI・JWT・bcrypt・Linux

  • FileGuard — 檔案完整性監控工具

    作品介紹

    角色：個人專案 / 獨立設計與開發

    偵測指定資料夾或檔案的未預期異動（新增・修改・刪除），設計初衷是在使用 AI 輔助開發工具時，掌握專案關鍵檔案（如 .env、設定檔）是否被意外更動。

    以 SHA256 雜湊比對判斷檔案內容是否真的改變（而非只看修改時間），並以 SQLite 儲存歷史事件與各檔案最新雜湊狀態，支援多個資料夾各自獨立的基準線。偵測到異動時，會透過系統桌面通知、提示音與 Discord Webhook 多管道提醒，任一管道失效都不影響監控本身。提供 Windows GUI（打包為正式安裝程式）與跨平台 CLI（Windows / Linux 驗證）兩種使用方式，共用同一套底層模組。

    負責：

    • 核心監控邏輯以定期掃描建立雜湊基準線，比對新舊狀態，判定新增 / 修改 / 刪除事件，支援排除資料夾與檔案樣式（避免編輯器暫存檔誤報）
    • 資料庫設計events 表保留完整歷史、files 表保存最新狀態；以 (folder, path) 組合主鍵讓不同監控目標互不干擾，解決切換資料夾時大量誤判刪除的問題
    • 雙介面共用架構將掃描、雜湊、資料庫抽成共用模組，GUI（customtkinter）與 CLI 僅負責呈現層
    • 容錯與跨平台於 WSL 無桌面環境測試時發現通知例外會中斷整個監控迴圈，改以 try/except 隔離各提醒管道；儲存路徑與提示音依作業系統切換
    • 打包與發布以 PyInstaller + Inno Setup 製作 Windows 安裝程式，並於另一台電腦實測，排除打包後圖示路徑遺失、plyer 動態模組未被打包等問題；GitHub Releases 發布，CLI 以 git clone 取得

    技術： Python・SQLite・SHA256（hashlib）・customtkinter・PyInstaller・Inno Setup・Discord Webhook
